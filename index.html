Exploring the relationship between gender, science and innovation

03 / KNOWLEDGE NETWORK ANALYSIS

Mapping connections between patents and scientific publications

Patent–publication relationships can be represented as a bipartite knowledge network. This makes it possible to explore how technological inventions connect to scientific knowledge sources.

Network definition: Patent nodes and scientific publication nodes are distinct. An edge represents a recorded patent–publication link. The visualisation below uses the edge list you upload; it does not invent connections or imply that the network has already been empirically analysed.

04 / PYTHON METHODS AND CODE DEMONSTRATIONS

From raw data to analytical outputs

The data processing and analytical workflow is implemented in Python. The website is the presentation layer; statistical analysis and network construction take place in the research workflow.

Data loading and inspection

Annual descriptive indicators

yearly = (
    patents.groupby("YearOfPatentGrant")
    .agg(
        patent_count=("patent_id", "count"),
        mean_female_ratio=("female_ratio", "mean"),
        mean_male_ratio=("male_ratio", "mean"),
        average_team_size=("team_size", "mean"),
        science_using_patents=("Uses_Science", "sum")
    )
    .reset_index()
)

yearly.to_csv(
    "yearly_patent_indicators.csv",
    index=False
)

Constructing a knowledge network

import pandas as pd
import networkx as nx

links = pd.read_stata("_patent_paper_pairs.dta")

edges = (
    links[["patent", "paperid"]]
    .drop_duplicates()
    .rename(columns={
        "patent": "source",
        "paperid": "target"
    })
)

edges["weight"] = 1

G = nx.Graph()

for _, row in edges.iterrows():
    G.add_node(row["source"], bipartite="patent")
    G.add_node(row["target"], bipartite="publication")
    G.add_edge(
        row["source"],
        row["target"],
        weight=row["weight"]
    )

degree = dict(G.degree())

Research scope and interpretation

The annual indicators are descriptive and do not establish causal effects. The patent–publication network represents knowledge linkages, not necessarily interpersonal social relationships. Network statistics depend on the selected nodes, edges, weights and projection methods.
